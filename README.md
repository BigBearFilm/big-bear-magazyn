# Big Bear Studio — Magazyn

Katalog rekwizytów. Hosting: GitHub Pages, logowanie i dane: Supabase.

Pliki w katalogu głównym stanowią gotową wersję statyczną. Kod źródłowy i konfiguracja kompilacji znajdują się w `source.zip`. Po rozpakowaniu: `npm ci`, następnie `npm run build`. Dane magazynu i zdjęcia wymagają zalogowania i nie są przechowywane w repozytorium.
